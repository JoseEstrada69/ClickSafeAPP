# ClickSafeAPP

## Descripción breve
Aplicación móvil para iOS diseñada para evitar estafas en plataformas de compra-venta
en linea.

## Datos técnicos
- Versión de Xcode: 26
- Modelo de iPhone en el simulador: iPhone 11

## Acuerdos básicos de colaboración
- No realizar cambios directamente en main.
- Desarrollar cada funcionalidad en una rama independiente (`feature/`).
- Utilizar mensajes de commit claros y descriptivos.
- Revisar el código mediante Pull Requests antes de integrarlo.
- Atender la retroalimentación recibida.
- Mantener una comunicación respetuosa y centrada en el código.

## Convención de ramas
`feature/NombreBreveDeLaFuncionalidad` (por ejemplo, `feature/MePrincipal`), siempre creada a partir de la versión más reciente de `main`.
